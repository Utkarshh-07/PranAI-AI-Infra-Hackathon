# Backend

This folder is a clean staging area for future backend services, APIs, database logic, and shared server-side utilities.

Planned contents:
- `backend/api/` for route handlers or HTTP endpoints
- `backend/database/` for models, migrations, and repository logic
- `backend/services/` for business logic
- `backend/utils/` for shared helpers

During the hackathon, this folder remains lightweight and can grow as the app evolves.
