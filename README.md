# PranAI

## Overview
PranAI is a hackathon project designed to showcase the power of AI in creating engaging and interactive experiences. This repository now includes an organized staging structure for frontend, shared logic, backend placeholders, and documentation.

## Folder Structure
```
PranAI/
├── backend/                     # Backend placeholders and future API/database logic
├── frontend/                    # Refactor-ready frontend wrappers and components
├── shared/                      # Shared models, services, and utilities
├── assets/                      # Static assets
├── configs/                     # Configuration files
├── docs/                        # Documentation
├── test/                        # Test files
├── tools/                       # Developer tools and scripts
```

## Getting Started
1. Clone the repository.
2. Navigate to the project directory.
3. Follow the setup instructions in the `docs/` folder.
